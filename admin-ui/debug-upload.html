📋 Quick Diagnosis Steps:

  1. Open the Calls page at http://localhost:5174/calls
  2. Open browser console (F12 → Console tab)
  3. Select a file and watch for:
    • "File selected: [filename]" message
    • Any error messages in red
  4. Click Upload button and watch for:
    • "Upload button clicked" message
    • "handleUpload called" message
    • "Starting upload for file" message
    • "uploadCall started" message

🔍 What to Check:

If NO console messages appear when clicking Upload:

  • ❌ Button click event not firing → React rendering issue
  • Fix: Check if button is actually disabled

If you see "File selected" but NOT "Upload button clicked":

  • ❌ Button is disabled or click handler not attached
  • Fix: Check selectedFile state management

If you see "handleUpload called" but NOT "uploadCall started":

  • ❌ Error in handleUpload before API call
  • Fix: Check for exceptions in the upload function

If you see "uploadCall started" but get an error:

  • ❌ Supabase connection or authentication issue
  • Look for specific error messages about:
    • Authentication (not logged in)
    • Organization membership
    • Storage bucket permissions

🛠️ Common Fixes:

1. Storage Bucket Permissions

Run this SQL in Supabase SQL Editor:

-- Allow authenticated users to upload
CREATE POLICY "Allow authenticated uploads" ON storage.objects
FOR INSERT TO authenticated
WITH CHECK (bucket_id = 'calls');

-- Allow authenticated users to view files
CREATE POLICY "Allow authenticated select" ON storage.objects
FOR SELECT TO authenticated
USING (bucket_id = 'calls');

2. Check Authentication

Make sure you're logged in. Check localStorage:

// In browser console:
localStorage.getItem('ai-sales-manager-auth')

3. Verify Environment Variables

Check that .env file has correct values:

VITE_SUPABASE_URL=https://[your-project].supabase.co
VITE_SUPABASE_ANON_KEY=eyJ...
