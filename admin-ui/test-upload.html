Upload Functionality Test

Manual Testing Steps:

  1. Open the admin UI at http://localhost:5174
  2. Log in with your credentials
  3. Navigate to the "Calls" page
  4. Try uploading an audio file
  5. You should see one of these outcomes:
    • ✅ Success message: "File uploaded successfully!"
    • ❌ Error: "Storage bucket 'calls' not found" - Follow the instructions shown
    • ❌ Error: "File size exceeds 50MB limit" - Choose a smaller file
    • ❌ Error: "Invalid file format" - Use MP3, WAV, M4A, or OGG

Quick Fix for Storage Bucket:

If you see the storage bucket error, here's the SQL to create it programmatically:

-- Run this in your Supabase SQL Editor:
INSERT INTO storage.buckets (id, name, public)
VALUES ('calls', 'calls', true);
